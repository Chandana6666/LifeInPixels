Life in Pixels

Life in Pixels is a full-stack journal and mood-tracking web application where users can save their daily memories, track moods, and visualize their life over time.

## Features

- memories can be added
- Track moods
- Store data in MongoDB Atlas
- RESTful API
- Express.js Backend

## Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
